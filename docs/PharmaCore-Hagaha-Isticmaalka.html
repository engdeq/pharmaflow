PharmaCore waa nidaam farmashiye: wuxuu maamulaa dawooyinka, iibka (POS), alaabta, iibsiga (purchases), macaamiisha, iyo warbixinaha — mid kasta wuxuu arkaa kaliya waxa uu fasax u leeyahay (roles & permissions).

4. Qaabka shaashadda

4.1 Sidebar (bidix)

  • Liiska modules-ka (Dashboard, POS, Medicines, …).
  • Qaar waa parent menu — guji si aad u furto submenu.
  • Mid keliya ayaa furan: mid cusub markaad furto, kii hore wuu xirmayaa.
  • Item-ka aad joogto wuxuu noqdaa buluug (active).

4.2 Topbar (kor)

  • Search / breadcrumbs
  • Theme (light/dark)
  • Profile → Logout

5. Yaa maxaa sameeyaa? (Roles)

Sharax kooxdaada sidaan:

RoleUjeeddoQaybaha ugu badan
Super Admin / Developer Xakameynta nidaamka oo dhan Users, Roles, Menus, Settings, Audit
Admin Maamul maalinle Almost all (maahan permissions.manage qaarkood)
Pharmacist Iibinta iyo dawooyinka POS, Medicines, Customers, Inventory view
Cashier Kaliya iib POS, Sales, Customers
Store / Inventory Manager Alaab & iibsi Inventory, Purchases, Expiry, Suppliers
Accountant Warbixino Reports, Sales/Purchases view
Sidebar-ku wuxuu muujiyaa kaliya menus-ka role-kaagu fasax u leeyahay. Haddii qof aan arkin module, waa permission — ma aha bug.

6. Habka shaqada maalinlaha (ugu fiican inaad u sheegto teamka)

  1. Subax: Hubi Dashboard (sales, low stock, expiry alerts).
  2. Alaab cusub: Purchases → Create Purchase → Approve → Inventory kor u kacaya.
  3. Iib: Point of Sale (POS) → dooro dawo → charge → sale la keydiyaa.
  4. Hubin: Sales History / Reports.
  5. Dhammaad maalin: Hubi Expiry + low stock, diyaarso purchase cusub haddii loo baahdo.

7. Qaybaha — mid mid

7.1 Dashboard

Sawir guud: iibka, alaabta, digniino. Ma wax lagu beddelo — waa overview.

7.2 Point of Sale (POS)

  1. Fur Point of Sale (POS) → New Sale.
  2. Raadi / dooro medicine.
  3. Geli quantity.
  4. Dhammee iibka (complete sale).
  5. Success dialog ayaa soo baxaya — stock ayaa hoos u dhaca.

Sales History = liiska iibkii hore (refunds/view).

7.3 Medicines

  • Medicine List — daawooyinka oo dhan (add / edit / delete).
  • Categories — noocyada (Antibiotic, Painkiller, …).
Ka hor intaadan iibin, medicine waa inuu jiraa + category + stock.

7.4 Inventory

  • Stock Levels — inta alaab ah ee hadda jirta; waxaad adjust-gareyn kartaa.
  • Expiry Management — dawooyinka dhacaya / dhacay.

7.5 Purchases (iibsiga laga keeno supplier)

SubmenuURL / macnahaMaxaad sameysaa
Pending Purchases /purchases Liiska iibsiga sugaya approval
Create Purchase /purchases/create Samee order cusub (supplier + medicine + qty + price + batch + expiry)
Incoming Purchases /purchases/incoming Kuwa la approve-gareeyay / soo galay
Rule: Create → Pending → Approve → Stock-ku wuu kordhaa.

7.6 Partners

  • Customers — macaamiisha (POS / credit).
  • Suppliers — shirkadaha aad ka iibsato.

7.7 Reports

Warbixino iib / purchase. Export haddii aad u baahan tahay analysis.

8. Save, Loading & Success (systemka oo dhan)

Markasta oo aad Save / Update / Delete / Approve sameyso:

  1. Loading dialog — “Saving… / Updating… / Deleting…” (sug).
  2. Success dialog — checkmark cagaaran + fariin (OK).
  3. Haddii qalad dhaco — toast casaan ah ayaa sheegaya fariinta.
Ha riixin Save laba jeer si degdeg ah inta loading-ku furan yahay.

9. Administration (kaliya maamulayaasha)

9.1 Users

  • Add User — username, email, password, roles.
  • Edit — beddel xogta.
  • Active / Inactive switch — Inactive = login ma shaqeeyo.
  • Reset PW — password cusub (default: ChangeMe@123).
  • admin (System Developer) — Locked: lama edit / disable / delete-gareyn karo.

9.2 Roles

  • Dooro role → Edit → checkbox permissions.
  • System roles (Super Admin, …) lama tirtiri / lama demin karo.
  • Active switch roles kale.

9.3 Menus

  • Sidebar menus waxay ka yimaadaan database.
  • Parent = group (URL madhan), Child = link dhabta ah.
  • Order ↑↓ + Parent dropdown.

9.4 Permissions / Audit / Settings

  • Permissions — liiska fasaxyada technical.
  • Audit Logs — cida wax beddeshay (security trail).
  • Settings — goobaha guud ee farmashiyaha.

12. FAQ degdeg ah

Q: Maxaan arkaa sidebar yar?
A: Role-kaagu wuxuu leeyahay permissions yar — sax role-ka Users/Roles.

Q: Purchase approve ka dib stock ma kordhin?
A: Hubi in approve uu guulaystay (success dialog) oo Inventory refresh garee.

Q: Password-kaygii waan illoobay?
A: Admin ha Reset PW sameeyo (maahan admin protected).

Q: Labo menu ayaa isku mid u muuqda active?
A: Accordion-ku waa exclusive; refresh / logout-login haddii browser cache duug yahay.
